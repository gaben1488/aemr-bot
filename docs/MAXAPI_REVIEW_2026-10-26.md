# MAX API: 1.2.1 → 1.2.3, проверка 26.10.2026

В aemr-bot закреплена `maxapi==1.2.1` в bot/pyproject.toml и bot/uv.lock.
Последний стабильный GitHub-релиз — v1.2.3, опубликован 05.10.2026 в 17:54 UTC
(06.10 в Камчатке). Поисковый индекс ещё показывал 1.2.2: проверен прямой
`GET /repos/love-apples/maxapi/releases/latest` и diff v1.2.1...v1.2.3.

Источники:

## Практический эффект для aemr-bot

| Изменение upstream | Что это даёт |
| --- | --- |
| Разбор polling-пачки без потери остальных обновлений при одном плохом событии | Меньше риска пропуска обращений из-за изменения формата MAX |
| Исправления start/stop/shutdown, включая Python 3.12+ | Надёжнее запуск, остановка и перезапуск |
| Жизненный цикл HTTP-сессий и коннекторов | Исправления закрытия/повторного использования соединений |
| Исправления HTTP-ответов, PureError при загрузке буфера | Предсказуемее сетевые ошибки и загрузка вложений |
| last_activity_time опционален | Ответ без этого поля не ломает валидацию пользователя |
| Сохранение path-префикса custom api_url | Полезно при API-шлюзе с префиксом пути |
| MaxError — общий базовый класс исключений | Можно точнее централизовать обработку ошибок SDK |
| SimpleEventIsolation / RedisEventIsolation | Последовательная обработка FSM-событий одного пользователя; ПО УМОЛЧАНИЮ ВЫКЛЮЧЕНА, нужна явная интеграция |
| set_commands; очистка commands=[] | Управление меню команд и его сброс |
| description в edit_chat | Редактирование описания чата |
| disable_link_preview в send_callback | Управление предпросмотром ссылок в callback-ответе |
| Методы /comments | Создание, чтение, редактирование и удаление комментариев к постам каналов; сценарии aemr-bot сами от этого не появятся |
| Проверка размера загрузок и документация лимитов | Предупреждения SDK; размер файла не гарантируется как доступный боту с ограниченной RAM |

Обновление зависимости не означает автоматическое появление интерфейсов
комментариев, новой логики рассылок, нейросетевой модерации или включение FSM
isolation. Они требуют отдельного кода, если нужны продукту.

В этом исправлении антифишинга версия SDK сохранена. По docs/DEPS.md переход
SDK должен идти отдельным PR: поднять точный пин, пересоздать lock, обновить
EXPECTED_MAXAPI_VERSION, прогнать тесты и проверить сетевые адаптеры/остановку.
Утверждать совместимость 1.2.3 на основании зелёного прогона с 1.2.1 нельзя.
Текущие изменения баз угроз не требуют новой версии maxapi.
